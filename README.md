# Create a .env file

You will need to use create a `.env` file with the following variables:

```dosini
FRESHSERVICE_URL = 'yourdomain.freshservice.com'
FRESHSERVICE_API_KEY = 'api_key'

SQL_USER = 'database_user'
SQL_PASSWORD = 'database_password'
SQL_SERVER = 'database_server'
SQL_DATABASE = 'database_name'

ACTIVE_DIRECTORY_URL = 'ldap://domain_controller1:389'
ACTIVE_DIRECTORY_BASE_DN = 'DC=example,DC=com'
ACTIVE_DIRECTORY_USER = 'someuser@example.com'
ACTIVE_DIRECTORY_PASSWORD = 'super_secret_password'
```
